# Auk edition of Blockbench

This is Auk Hosting's fork of [Blockbench](https://github.com/JannisX11/blockbench) (GPL-3.0).
It is embedded in the Auk website so server owners can make logos, titles and server icons.
It is **not** the official Blockbench. Upstream's `LICENSE.MD` and copyright notices are kept,
and every change in this fork is GPL-3.0 too. Source: https://github.com/ItzJustNett/auk-blockbench

Branches: `master` tracks upstream (`JannisX11/blockbench`), `auk` holds our changes.

## Build and run (web version)

Needs Node.js 20+.

```sh
npm ci                                   # install dependencies
npm run build-web                        # one-off build: dist/bundle.js (minified)
node ./build.js --target=web --serve --port 4280 --host 127.0.0.1
                                         # dev server with rebuild on reload: http://127.0.0.1:4280/
```

`npm run serve` is the same dev server on esbuild's default port. The web build is plain static
files: `index.html`, `dist/`, `css/`, `assets/`, `font/`, `lang/`, `lib/` and friends can be served
by any static host once `npm run build-web` has run. (`npm run prepublish-web` also builds the PWA
service worker and the docs.)

## What Auk adds

All Auk code lives in `js/auk/` and is loaded at startup by `js/boot_loader.js`
(`loadAukPlugins()`), so it ships with the app and never comes from the plugin store.

- `js/auk/title/`: **Auk Title** (`auk_title`), a project type for Minecraft-style 3D titles made
  from text (see the spec below). Our own block fonts, procedural materials, no third-party assets.
- `js/auk/save_to_auk.js`: **Save to Auk** (`save_to_auk`). When the app runs inside an iframe
  opened with `?auk_origin=<origin>`, the File menu (and the title's Render panel) gets
  "Save to Auk". It renders a PNG and sends it to the parent page:

  ```js
  window.parent.postMessage({ type: "auk:image", kind: "title" | "icon", png: "<base64>", width, height }, auk_origin)
  ```

  `png` is the base64 PNG without the `data:` prefix. An `icon` is always 64×64 (Minecraft's
  `server-icon.png`). On load the app also sends `{ type: "auk:ready" }` to the same origin.
  `auk_origin` must be on the allowlist in `save_to_auk.js` (`https://auk-hosting.com`,
  `http://localhost:5173`); when the app itself is served from `localhost`/`127.0.0.1`, any
  `http://localhost:<port>` or `http://127.0.0.1:<port>` origin is accepted too, for development.
  Anything else is ignored and the action stays hidden. Messages are never posted to `"*"`.
- "Based on Blockbench · Source" links on the start screen and in the About dialog.
- `docs/auk/`: screenshots and test pages (`docs/auk/iframe-test.html` iframes the app and logs
  the messages it receives).

## Title generator: clean-room rules

There is a third-party Blockbench plugin with a similar goal ("Minecraft Title Generator" by Ewan
Howell). Its code has no license and some of its textures are Mojang's. We build our own
equivalent without its code or assets:

- Only its public descriptions were read: the plugin's `about.md` and `changelog.json` in
  `JannisX11/blockbench-plugins`, its `plugins.json` listing, its web page, and the `README.md` of
  its asset repository. Never its `.js` source, nor its fonts, shapes, tileables or scripts.
- Fonts (block glyphs), materials and textures here are drawn or generated by us. No Mojang
  textures or other third-party assets anywhere.

## Title generator: feature spec

Every feature learned from the public descriptions, and whether Auk Title has it in stage 1.

| # | Feature (as described publicly) | Auk Title |
|---|---|---|
| 1 | A dedicated project type, started from the start screen or File > New | in stage 1 |
| 2 | A pop-up dialog on project creation to enter the text (and pick the text type) | in stage 1 |
| 3 | Several text elements per project, each with a text type (e.g. top / bottom text); picking the bottom type turns on "fade edges to the border colour" | in stage 1 (types: Title, Subtitle, Small; Subtitle fades by default) |
| 4 | "Add Text" button in the outliner | in stage 1 |
| 5 | Several fonts to choose from, with descriptions, example text, a "more info" button and a list of available characters | in stage 1 (two fonts of our own, character list); thumbnails later |
| 6 | Font variants (alternative character designs or character sets), in their own tab | later |
| 7 | Character spacing (with a per-font default) and a configurable space width | in stage 1 |
| 8 | Character shifting / kerning pairs | later |
| 9 | Start and end line terminators | later |
| 10 | Character borders, or an automatic border around a whole row; flat (no depth) fonts | in stage 1 (outline around the row's letters, any depth incl. near-flat) |
| 11 | Textures per font: presets with categories and variants, search with a clear button, lazy-loaded thumbnails | in stage 1 as procedural material presets (stone, cobble, gold, wood, grass, ice, obsidian, lava, bricks, emerald); search, categories and thumbnails later |
| 12 | Custom texture upload | later |
| 13 | Gradient fill | in stage 1 (two or three stops) |
| 14 | Colour tint with an opacity slider | in stage 1 |
| 15 | Overlays over the texture, with an opacity slider; fonts' built-in overlay can be turned off; custom overlay can be removed | in stage 1 as procedural overlays (shine, noise, stripes, sparkle) with opacity; custom overlay later |
| 16 | "Tileables": a small texture repeated over each character's faces, random rotation / mirroring, resolution 1-4 | later (custom tile upload); the procedural materials already tile |
| 17 | Fade the edges (sides) to the border colour; a single border colour | in stage 1 |
| 18 | Shapes: non-text elements (single models) that can be added next to text | later |
| 19 | A Render tab for high-quality renders, with a render output dialog (resolution and more) | in stage 1 (Render mode: size presets, anti-aliasing, background, PNG export) |
| 20 | "Position Camera" button that sets the camera for you; the title angle in the Angles menu; the angle is loaded on project creation | in stage 1 |
| 21 | Presets: save, load and delete (with confirmation) all settings | later |
| 22 | Export the generated texture as a texture preset | later |
| 23 | A debug action that loads text with every character of a font | in stage 1 ("Show all characters") |
| 24 | Agreement to the Minecraft EULA before use (because Mojang textures ship with it) | not needed: no Mojang assets |
| 25 | CDN fallbacks and offline warnings for remotely loaded fonts and textures | not needed: everything is bundled or generated locally |
| 26 | A CSS class on the format page so themes can target it | in stage 1 |

Auk additions: Ukrainian Cyrillic capitals in both fonts, bevel shading on the front faces,
texture resolution setting, per-row size / depth / offset, "Save to Auk" (title PNG and 64×64 icon).
